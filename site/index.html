DETERMINISTIC ENGINE ARCHITECTURE

Built for private ownership and verifiable math.

Every metric in Trading Bauhaus—from FIFO round-trip matching to Edge Score v2—runs on documented TypeScript formulas backed by isolated SQLite storage.

01 / INGESTION

Broker & CSV Sync

Import NinjaTrader, TradingView, IBKR, or CSV fills with automatic timezone normalization and fee preservation.

02 / MATCHING

FIFO Round-Trip Engine

Reconstructs raw executions into closed round trips with exact realized R multiples, duration, and pro-rata fees.

03 / SCORING

Open Edge Score v2

Pinned 0–100 weighted score across Win % (15), Profit Factor (25), Avg Win/Loss (20), Drawdown (15), Recovery (10), and Consistency (15).

04 / REFLECTION

Grounded AI & Replay

Candle replay inspects MAE/MFE bar by bar while optional BYOK AI answers cite actual filtered journal numbers.

Isolated SQLite Databases

Owner and invited member records live in separate SQLite files under JOURNAL_DATA_DIR with zero shared multi-tenant tables.

Zero External Telemetry

Self-hosted deployments store credentials encrypted at rest using JOURNAL_SECRET with no third-party analytics tracking.

Non-Load-Bearing Color

Every monetary readout pairs color with signed numbers, zero baselines, and distinct win/loss shapes for accessibility.

SELF-HOST QUICKSTART

Run Trading Bauhaus on your own machine or server.

Requires Node 22+ and pnpm 11.25.0, or Docker Compose. Local databases initialize automatically on first boot.

Local Development (Node 22 + pnpm) 
pnpm install --frozen-lockfile
pnpm dev
# Open http://localhost:3000
Docker Compose (Persistent ./data volume) 
docker compose up -d
# http://localhost:3000 · SQLite persists under ./data

Essential Environment Variables

  • JOURNAL_PASSWORD

    Optional password to lock a self-hosted instance. Leave unset for instant dashboard access.

  • JOURNAL_MULTI_USER

    Optional multi-user mode (set to true) for isolated per-member SQLite databases.

  • JOURNAL_SECRET

    Encryption key source protecting stored broker credentials and API keys at rest.
